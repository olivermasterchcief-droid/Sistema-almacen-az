# 🏭 Sistema Integrado AZ — Gestión de Almacén y Rastreo

Sistema de escritorio desarrollado en Python con interfaz futurista 
animada para la gestión integral de materiales, rastreo de cajas 
y análisis predictivo de inventario.

## 🚀 Características

- Dashboard ejecutivo con KPIs en tiempo real
- Pronóstico inteligente de inventario basado en consumo histórico
- Recomendaciones automáticas de compra
- Alertas de stock mínimo
- Rastreo de cajas con historial de movimientos
- Kardex de entradas y salidas por material
- Ficha detallada por material con fotografía
- Configuración con backup automático de base de datos
- Animaciones ambientales fluidas
- Navegación por menú lateral

## 🛠️ Tecnologías

- Python 3
- CustomTkinter (interfaz dark mode animada)
- SQLite3 (base de datos local)
- Pillow (manejo de imágenes)

## 💡 Problema que resuelve

Reemplaza el control manual de inventario en almacén industrial, 
integrando trazabilidad, análisis predictivo y dashboards ejecutivos 
en un solo sistema de escritorio.
